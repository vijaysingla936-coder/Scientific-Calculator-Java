# Scientific Calculator - Java

A simple and easy Scientific Calculator built in Core Java by **Vijay Singla - Hodal**

![Java](https://img.shields.io/badge/Java-17%2B-orange) ![Lines](https://img.shields.io/badge/Lines-3000%2B-blue)

## 🚀 Features

### 1. Basic Operations
- Addition, Subtraction, Multiplication, Division
- Modulus, Percentage
- Clear (C), Delete

### 2. Scientific Functions
- Trigonometric: sin, cos, tan (in degrees)
- Logarithmic: log10, ln
- Power: x^y, x^2, x^3
- Square Root, Cube Root
- Factorial, Exponential

### 3. Advanced Modules Added
- **AdvancedOperations.java** - All scientific calculations
- **Converter.java** - Length, Weight, Temperature, Area, Volume, Currency conversion
- **HistoryManager.java** - Save, Search, Export calculation history with timestamp
- **ScientificCalculatorUI.java** - Swing based beautiful UI with 5x5 grid
- **Themes.java** - 4 Themes (Dark, Light, Neon, Ocean) with custom fonts

### 4. UI Features
- Responsive Swing UI
- 25 Buttons with scientific functions
- Display with error handling
- Theme support
